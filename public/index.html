    dotenvx guide

    Work with an environment file

    dotenvx keeps encrypted values in your normal .env files and stores the private keys separately.

    1. 1
      Open a project

      Choose a folder, then select the environment file you want to work with.

    2. 2
      Edit values

      Values stay masked until you reveal them. Changes are written through dotenvx set.

    3. 3
      Encrypt before committing

      Choose Encrypt file and confirm every secret value is marked Encrypted.

    .envCommit only after its secret values are encrypted.
    .env.keysPrivate decryption keys. Keep this file out of Git.

    Ship an encrypted environment

    Your repository gets the encrypted file. Your deployment platform gets the matching private key.

    1. 1
      Encrypt the selected file

      For example, encrypt .env.production before staging it.

    2. 2
      Store its private key

      Copy the matching key from .env.keys into your deployment platform's secret settings.

    3. 3
      Run through dotenvx

      Start the application with dotenvx run -- your-command.

    Keep private keys out of version control. Share them only through your deployment platform or a trusted secret manager.
